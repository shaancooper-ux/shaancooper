# Shaan Cooper — Engineering Portfolio

Static aerospace engineering portfolio with project images and a downloadable résumé.

## Website

https://shaancooper-ux.github.io/shaancooper/

## Editing

- Edit `index.html` to update the portfolio text, layout, and styles.
- Project images are stored in `assets/`.
- Replace `assets/Shaan-Cooper-Resume.pdf` to update the résumé while preserving its download link.

## Hosting

GitHub Pages should publish from the `main` branch and the repository root (`/`). The `.nojekyll` file allows the static files to be served directly.
